# 1. Record architecture decisions

Date: 2026-10-01

## Status
Accepted

## Context
Agents and humans both make design decisions on this project. Later sessions need to know why things are the way they are.

## Decision
Record significant decisions as lightweight ADRs in `docs/adr/`, numbered sequentially, with sections Status, Context, Decision, Consequences.

## Consequences
Agents read ADRs before changing structure, and add one whenever they introduce a new dependency, pattern, or architectural rule.
